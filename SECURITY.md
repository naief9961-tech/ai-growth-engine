# NAIF Gravity security policy

## Report a vulnerability privately

If you find a security issue in this repository or a NAIF Gravity service listed here, email [naief9961@gmail.com](mailto:naief9961@gmail.com) with the subject **NAIF Gravity security report**. Please do not post vulnerability details in a public issue or pull request.

Include the affected component and version or commit (if known), what you observed, the potential impact, and minimal steps to reproduce with synthetic data. Redact credentials, tokens, wallet keys, personal information and customer data. You do not need to make a payment or test a live customer account to submit a report.

## الإبلاغ عن ثغرة

إذا وجدت مشكلة أمنية في هذا المستودع أو في إحدى خدمات NAIF Gravity المذكورة فيه، فأرسل بلاغًا خاصًا إلى [naief9961@gmail.com](mailto:naief9961@gmail.com) بعنوان **بلاغ أمني — NAIF Gravity**. لا تنشر تفاصيل الثغرة في بلاغ عام أو طلب دمج.

اذكر المكوّن المتأثر وإصداره إن عُرف، وما لاحظته، والأثر المحتمل، وأقل خطوات تكفي لإعادة المشكلة ببيانات تجريبية. احذف كلمات المرور والرموز ومفاتيح المحافظ والبيانات الشخصية وبيانات العملاء. لا يلزم إجراء دفعة أو اختبار حساب عميل لإرسال البلاغ.
